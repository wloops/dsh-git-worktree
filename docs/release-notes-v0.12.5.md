# v0.12.5 — 恢复 DSH 0.2.2-rc.3 的 Worktree 侧栏聚合

## 本版目的

DSH `0.2.2-rc.3` 此前未被精确版本适配识别，因此保留官方 Workspace 列表，托管 Worktree 会话未聚合到原项目下。官方公开扩展点可装饰列表行，但还不能改变会话的分组。

## 主要更新

- **恢复托管 Worktree 会话聚合与状态标记**：为 `0.2.2-rc.3` 增加独立的 `modern-022-rc3` 适配，使用精确版本和 SHA-256 校验的官方 Workspace 构建产物，保留新版列表、搜索和菜单。聚合只改变侧栏展示，不改变 Session ID 或持久化的工作区归属。
- **保留未知版本的官方回退**：不复用其他版本的列表适配；仅在官方声明相应扩展槽时添加 Worktree 标记。

## 兼容与使用说明

无需数据迁移。DSH peer 最低版本仍为 `0.2.1-rc.2`，保留对 `0.2.2-rc.1` 的显式安装范围，并加入 `0.2.2-rc.3`；运行时 singleton 仍由宿主提供。允许安装不等于已完成宿主验收。未验证 `0.2.2-rc.5`，不声明支持该版本。
