# v0.12.4 — 托管会话「新会话」入口修复与状态胶囊收敛

状态：候选。待 clean Local 门禁与精确提交 CI 通过后打 tag、创建 GitHub Release 并发布 npm。

## 本版目的

修复两个托管 Worktree 会话的界面问题：侧栏「新会话」在托管会话中点击无反应，以及无 Worktree 目标的会话残留状态胶囊。无数据迁移、无破坏性变更。

## 主要更新

- **修复托管 Worktree 会话中「新会话」无反应**：全局新会话隐式解析到托管工作区时重定向到原项目工作区；拓扑未就绪或映射缺失时打开新会话视图而非静默失败；显式在托管工作区创建第二会话仍受保护，普通路径行为不变。新增 5 代派生隐式解析回归与 guard 映射写入验证。
- **隐藏无 Worktree 目标会话的状态入口**：加载中、查询失败或项目不是可用 Worktree 时不再渲染状态胶囊或提示；有目标时的状态展示与操作错误反馈保持不变。新增零渲染回归并反转加载态断言。

## 兼容与使用说明

无数据迁移、无破坏性变更，升级路径与 `0.12.3` 相同。DSH peers 与构建基线保持不变，运行时 singleton 仍由宿主提供。`0.1.x` Host 继续使用 `0.9.x` 插件线。
